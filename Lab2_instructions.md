# Лабораторная работа 2 Раздел 3

В проект добавлены проверки uid и operationUid (обязательность, максимум 32 символа), systemTime (обязательность) и communicationId (от 1 до 100000 включительно). Аннотация @Valid включает проверку входящего JSON. Остальные поля необязательны. Формат времени отдельно не ограничивается: в таблице задания для systemTime указана только обязательность.

Если uid равен строке "123", выбрасывается собственное UnsupportedCodeException. Ответ содержит HTTP 400, code="failed", errorCode="UnsupportedCodeException". Сначала проверяются ограничения полей, затем специальное значение uid.

Ошибки ограничений возвращают HTTP 400 и errorCode="ValidationException". В errorMessage перечисляются все ошибки полей. Успешный запрос возвращает HTTP 200 и code="success".

## Проверка в Postman

1. Перезапустите MyFirstTestAppSpringBootApplication в IntelliJ IDEA. Порт приложения — 8082.
2. В Postman нажмите Import и выберите Lab2.postman_collection.json из папки проекта (рядом с pom.xml).
3. Появится коллекция «ЛР 2 — Валидация REST сервиса» с папкой «Раздел 3 — тесты валидации» и 27 запросами. Для каждого уже настроены POST, адрес, JSON и автоматические проверки ответа.
4. Откройте первый запрос и нажмите Send. Должен вернуться HTTP 200.
5. По очереди отправьте остальные запросы. Ошибочные значения должны возвращать HTTP 400. На вкладке результатов тестов должны проходить проверки.
6. Для запуска всех запросов откройте меню коллекции и выберите Run collection, затем запустите выполнение.

## Скриншоты для отчёта

Сделайте реальные скриншоты Postman: отдельные ошибки каждого проверяемого поля, превышение длины обоих идентификаторов, значения communicationId вне диапазона, запрос со всеми ошибками одновременно и запрос uid="123". На снимке должны быть видны отправленный JSON, HTTP-статус и ответ сервиса.

Отдельно сделайте скриншот развёрнутой коллекции со списком запросов и результатов общего запуска. Коллекция подготовлена; скриншоты интерфейса Postman нужно сделать после импорта и выполнения запросов.

## Автоматические тесты

FeedbackValidationTests запускает приложение на свободном порту и отправляет 27 реальных HTTP-запросов из той же коллекции, проверяя статус, code, errorCode и наличие ошибок нужных полей. Выполнить тесты можно через Maven → Lifecycle → test в IntelliJ IDEA.
